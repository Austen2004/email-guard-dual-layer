🔌 How to Connect DualShield to Real Live Gmail

DualShield is built modularly. You can run it locally in demonstration mode (as currently running), or link it to your actual Google Gmail mailbox via either **Gmail IMAP (App Password)** or **Google Cloud Gmail API**.

Method A: Fast 2-Minute Setup with Gmail App Password (IMAP)

  1. Visit your Google Account settings: myaccount.google.com/apppasswords.
  2. Create an App Password labeled "DualShield Guard" (16 characters).
  3. In your DualShield directory, run the live connector: 
    python -c "from gmail_service import LiveGmailIMAPConnector; conn = LiveGmailIMAPConnector('your.email@gmail.com', 'your-16-char-app-password'); print(conn.fetch_and_scan_unread())"
  4. DualShield will inspect your unread messages, flag threats, and output security alerts!

Method B: Enterprise Production Setup with Google Cloud Gmail API

For production enterprise defense, register an OAuth 2.0 Client in Google Cloud Console with https://www.googleapis.com/auth/gmail.modify scope. DualShield automatically applies Gmail labels:

  • [DualShield/Quarantined]: Messages removed from Inbox and isolated.
  • [DualShield/Suspicious]: Message gets warning label and injected safety header.
  • [DualShield/VerifiedSafe]: Confirmed genuine sender.
